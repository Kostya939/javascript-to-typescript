# TypeScript E-commerce Components with Generics

This project demonstrates the use of TypeScript generics to create type-safe functions for managing various product types in a basic e-commerce system. 

## Project Structure

- **src/types/** – Contains type definitions for `BaseProduct`, `Electronics`, `Clothing`, and `CartItem`.
- **src/functions/** – Includes functions for finding products, filtering by price, adding items to the cart, and calculating the total price.
- **src/test/** – Contains sample data for different product types (e.g., electronics and clothing).
