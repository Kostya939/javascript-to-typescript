# University Management System

### Мета роботи
Цей проект демонструє використання TypeScript для створення системи управління навчальним процесом університету з використанням типів, інтерфейсів, перерахувань (`Enum`) та інших сучасних можливостей TypeScript.

---

## Особливості
- **Перерахування (Enums):**
  - Статуси студентів (`StudentStatus`)
  - Типи курсів (`CourseType`)
  - Семестри (`Semester`)
  - Оцінки (`Grade`)
  - Факультети (`Faculty`)

- **Інтерфейси:**
  - `Student`
  - `Course`
  - `Grade`

- **Клас `UniversityManagementSystem`:**
  - Реалізує функціональність управління студентами, курсами та оцінками.

- **Основні методи:**
  - Додавання студента
  - Реєстрація на курс
  - Виставлення оцінки
  - Оновлення статусу студента
  - Розрахунок середнього балу
  - Отримання списку доступних курсів
  - Перегляд студентів факультету
